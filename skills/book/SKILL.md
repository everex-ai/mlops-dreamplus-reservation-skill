# 드림플러스 회의실 예약

원하는 조건으로 예약하고, 불가하면 가까운 빈 회의실을 제안한다.
**포인트가 즉시 차감되므로 `--confirm` 은 사용자 확인을 받은 뒤에만 붙인다.**

> 경로: 이 스킬 base 디렉토리의 **두 단계 상위가 플러그인 루트**(`REPO`).
> 로그인·네트워크는 스크립트가 직접 처리한다. 브라우저는 쓰지 않는다.

## 절차

1. **요청 파악** — 회의실(또는 정원/장비 조건), 날짜(기본 오늘), 시작 시간, 종료(기본 시작+30분),
   미팅명. 조건으로만 말했으면 `REPO/data/rooms.catalog.json`에서 후보를 고른다.

2. **확인용 실행 (dry-run)** — `--confirm` 없이 실행하면 **예약하지 않고** 계획만 출력한다.
   ```
   node REPO/bin/book.mjs <회의실> <시작 HH:mm> [종료] --date <YYYY.MM.DD> --title '<미팅명>'
   ```
   - 🟢 **가능**: 회의실·시간·차감 포인트가 출력된다 → 3번으로.
   - 🔴 **불가**: 가까운 빈 회의실 후보가 나온다. 어느 방으로 할지 사용자에게 묻고,
     **고른 회의실로 2번을 다시 실행**한다.
     (요청한 방이 차 있으면 `--confirm` 을 붙여도 예약되지 않는다 — 확인 안 받은 방을 잡지 않기 위해서다.)

3. **사용자 확인** — 회의실·날짜·시간·**차감 포인트**를 요약해 예약할지 확인받는다.

4. **예약 실행** — 확인되면 2번과 **똑같은 명령에 `--confirm` 만 추가**해 실행한다.
   ```
   node REPO/bin/book.mjs <회의실> <시작> [종료] --date <YYYY.MM.DD> --title '<미팅명>' --confirm
   ```
   `✅ 예약 완료`가 나오면 사용자에게 알린다.

## 참고

- 운영시간은 08:00~21:00, 30분 단위다. 벗어나면 스크립트가 거부한다.
- 자격증명이 없으면 스크립트가 설정 방법을 안내하며 종료한다(종료코드 2).
  그 안내를 그대로 전달하고, **비밀번호를 대신 입력하거나 대화창에서 묻지 않는다.**
- 토큰 만료는 스크립트가 자동으로 재로그인해 처리한다.
