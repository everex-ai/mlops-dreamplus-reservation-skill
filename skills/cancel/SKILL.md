# 드림플러스 예약 취소

내 예약을 특정해 취소한다. **`--confirm` 은 사용자 확인을 받은 뒤에만 붙인다.**

> 경로: 이 스킬 base 디렉토리의 **두 단계 상위가 플러그인 루트**(`REPO`).
> 로그인·네트워크는 스크립트가 직접 처리한다. 브라우저는 쓰지 않는다.

## 절차

1. **대상 확인 (dry-run)** — `--confirm` 없이 실행하면 **취소하지 않고** 대상만 출력한다.
   ```
   node REPO/bin/cancel.mjs [<회의실> [시작 HH:mm]] [--id <N>] --date <YYYY.MM.DD>
   ```
   - 대상이 **1개**면 `🗑️ 취소 대상 —` 한 줄이 나온다 → 2번으로.
   - **여러 개**면 목록이 나온다. 사용자에게 물어 `--id <N>`으로 좁힌 뒤 다시 실행한다.
     (대상이 2개 이상이면 `--confirm` 을 붙여도 취소되지 않는다.)
   - **없으면** 그 날짜의 내 예약 목록을 보여주므로 그대로 전달한다.

2. **사용자 확인** — 취소 대상(회의실·시간·제목)을 보여주고 취소할지 확인받는다.

3. **취소 실행** — 확인되면 1번과 **똑같은 명령에 `--confirm` 만 추가**해 실행한다.
   ```
   node REPO/bin/cancel.mjs [<회의실> [시작]] [--id <N>] --date <YYYY.MM.DD> --confirm
   ```
   `✅ 취소 완료`가 나오면 사용자에게 알린다.

## 참고

- 취소는 **시작 30분 전까지**만 가능하다. 늦었으면 API가 사유를 반환하므로 그대로 전달한다.
- 같은 날 취소면 포인트가 환불된다.
- 자격증명이 없으면 스크립트가 설정 방법을 안내하며 종료한다(종료코드 2).
  그 안내를 그대로 전달하고, **비밀번호를 대신 입력하거나 대화창에서 묻지 않는다.**
